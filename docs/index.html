Overview

Direct Linux HID Driver

Communicates directly with the MSI keyboard microcontroller via /dev/hidraw* using reverse-engineered Feature Reports (0x01, 0x02, 0xA0). Zero external daemon required.

< 1ms Latency Pure Rust

Onboard EEPROM Flash Persistence

Emits packet 0xA0 to commit colors to keyboard flash. When you reboot or power on, your chosen lighting is displayed at the BIOS/UEFI level without any software running.

Survives Reboots Zero Memory Leaks

Synchronized Whole-Keyboard Engine

Eliminates the internal firmware 90° spatial phase delay by driving Mode 1 Steady synchronously across all 4 zones (0x0F) at 33 FPS for butter-smooth color transitions.

100% Uniform No Flashing

GTK4 GUI & Headless CLI

Includes a clean GTK4 user interface with live color wheel, profile manager, and key visualizer, alongside a robust CLI designed for terminal users and window manager keybinds.

Hyprland Ready Wayland & X11

Installation

1. Install via Cargo (Recommended)

Ensure you have GTK4 development headers installed on your system, then install directly from crates.io:

Terminal
$cargo install msi-rgb

System dependencies:
• Fedora: sudo dnf install gtk4-devel cairo-gobject-devel glib2-devel pkgconf-pkg-config
• Ubuntu / Debian: sudo apt install libgtk-4-dev libcairo2-dev libglib2.0-dev pkg-config
• Arch Linux: sudo pacman -S gtk4 cairo glib2 pkgconf

2. 1-Line Installer via cURL (Alternative)

Installs dependencies, builds from source, sets up desktop launcher and icons:

Terminal
$curl -fsSL https://raw.githubusercontent.com/jeremylanes/msi-rgb/main/bin/install.sh | bash -s -- --user

Udev Configuration (Non-Root Access)

To communicate with the keyboard HID device without requiring sudo, place the udev rule in /etc/udev/rules.d/99-msi-rgb.rules:

Udev Rule
SUBSYSTEM=="hidraw", ATTRS{idVendor}=="1462", ATTRS{idProduct}=="1601", MODE="0666", TAG+="uaccess"

Reload rules with: sudo udevadm control --reload-rules && sudo udevadm trigger

Philosophy & Origins

Born from Linux Necessity: When unboxing the MSI Katana 15 HX B14W on Fedora Linux, there was no native Linux utility available to manage keyboard illumination. Proprietary software was Windows-only, and existing generic lighting tools lacked proper direct HID protocol support for the MS-1565 microcontroller.

msi-rgb was created to give Linux users total sovereignty over their hardware: direct USB HID feature reports, zero background bloat, hardware EEPROM flash persistence, and seamless Hyprland/Sway integration.

Engineering & Methodology: This project is entirely vibecoded and engineered using autonomous agent pair-programming with Google Antigravity (AGY) and the BMad Method.
